Open and save Markdown

Choose File → Open or press Command-O to open a Markdown file. You can also drag a file onto Skimmy’s Dock icon.

Choose File → New (Command-N) for a blank document. Press Command-S to save.

Read and edit

  • Read shows the formatted document.
  • Edit lets you change the formatted text directly. Press Command-E to switch between Read and Edit.
  • Source lets you type Markdown syntax directly.

Skimmy preserves the source of blocks you leave alone. Formatting syntax in an edited block can change when you save it. Use Source if you want to control the exact Markdown.

In Edit, use Format to apply headings, emphasis, inline code, and lists, or to insert or edit a link. Click a task checkbox to update it in the Markdown file.

Use Command-Z to undo an edit and Shift-Command-Z to redo it.

Find text and jump to headings

Press Command-F, enter your search, then press Return. Use Command-G for the next match and Shift-Command-G for the previous match. Press Escape to close the find bar.

In Edit, use Replace to change the current match or Replace All to change every match in the document.

Press Shift-Command-L to show or hide the sidebar. Choose Contents to jump to a heading or Links to browse the links in the document.

Change appearance and text size

Choose Skimmy → Settings (Command-Comma) and select System, Light, or Dark. System uses your Mac’s appearance setting.

Use the text-size buttons in the toolbar or choose commands in the View menu. Press Command-0 to reset the text size.
